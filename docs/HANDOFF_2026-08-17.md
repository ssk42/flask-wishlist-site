the PR run caught three real bugs:

1. **Migration downgrade broken** (FIXED, committed to the branch):

   created by the previous migration — failed on Postgres. Now a pure no-op;
   `3bf7272ee759` owns teardown and drops the table directly (batch-op `f()`
   index drops removed — redundant and broken on PG). Migration job now passes.

   against ALL current typer versions (`typer.rich_utils` AttributeError).
   Replaced with `pip-audit -r requirements.txt` in the workflow.

   this is the remaining red job): `ios/Wishlist/Intents/OpenWishlistItemIntent.swift`
   and `SearchWishlistIntent.swift` use `@AppIntent`, which the runner's
   Xcode 16.4 (macos-15 image) rejects: `unknown attribute 'AppIntent'`.
   This is a **main-branch problem** the new gate surfaced — the intents were
   merged from the Siri work and require a newer SDK than the runner has
   (locally it builds against Xcode-beta 27). Do NOT merge #63 until this is
   resolved, or main's CI will be permanently red.

   Options for the next agent (pick one):
